# مصنع الشورتس 🎬

نظام آلي يصنع مقاطع **YouTube Shorts** وينشرها على قناتك يومياً بدون تدخل منك:

```
فكرة جديدة ← نص قصير جذاب ← تعليق صوتي عربي ← فيديو عمودي بترجمة متحركة ← رفع على يوتيوب
```

- **الأفكار والنصوص:** يكتبها Claude (حقائق مدهشة صحيحة، بداية تشد المشاهد، دعوة للمتابعة). بدون مفتاح يستخدم بنك 12 فكرة جاهزة.
- **الصوت:** صوت عربي طبيعي مجاني (Microsoft Edge TTS – `ar-SA-HamedNeural`).
- **الصورة:** فيديوهات خلفية مجانية من Pexels حسب الموضوع، أو خلفية متحركة ملونة.
- **الترجمة:** كلمات كبيرة متحركة بالعربي + شريط تقدم أسفل الشاشة (يرفع نسبة المشاهدة للنهاية).
- **النشر:** رفع تلقائي عبر YouTube API مرتين يومياً، ولا يكرر أي موضوع سبق نشره.
- **التشغيل:** على GitHub Actions مجاناً – لا تحتاج كمبيوتر شغال.

## خطوات التشغيل (مرة واحدة، حوالي 30 دقيقة)

### 1) القناة
أنشئ قناة يوتيوب بحساب Google (يفضّل حساب مخصص للقناة). اختر اسماً وصورة تناسب "حقائق يومية".

### 2) مفتاح Claude (لأفكار لا تنتهي)
من [console.anthropic.com](https://console.anthropic.com) ← API Keys ← أنشئ مفتاحاً. تكلفة الفيديو الواحد أقل من سنت تقريباً.

### 3) مفتاح Pexels (لفيديوهات الخلفية – مجاني)
سجّل في [pexels.com/api](https://www.pexels.com/api/) وانسخ المفتاح.

### 4) صلاحية الرفع على يوتيوب
1. ادخل [console.cloud.google.com](https://console.cloud.google.com) وأنشئ مشروعاً جديداً.
2. **APIs & Services ← Library** ← فعّل **YouTube Data API v3**.
3. **OAuth consent screen**: النوع External، أضف إيميلك كـ Test user، ثم اضغط **Publish app** (مهم: بدونها ينتهي التوكن كل 7 أيام).
4. **Credentials ← Create credentials ← OAuth client ID** ← النوع **Desktop app** ← نزّل ملف JSON وسمّه `client_secret.json`.
5. على كمبيوترك (مرة واحدة فقط):
   ```bash
   pip install google-auth-oauthlib
   python scripts/get_youtube_token.py client_secret.json
   ```
   سجّل دخول بحساب القناة، وسيطبع لك 3 قيم.

> ⚠️ **مهم:** يوتيوب يجعل الفيديوهات المرفوعة من مشاريع API الجديدة **خاصة (Private)** حتى يتم تدقيق المشروع. قدّم طلب التدقيق المجاني من [نموذج YouTube API Audit](https://support.google.com/youtube/contact/yt_api_form). إلى أن يُقبل: النظام يحفظ كل فيديو في GitHub (قسم Artifacts) وتقدر تنزله وترفعه بنفسك من جوالك في دقيقة، أو تغيّر خصوصيته إلى عام من YouTube Studio.

### 5) أضف المفاتيح في GitHub
في المستودع: **Settings ← Secrets and variables ← Actions ← New repository secret**:

| الاسم | القيمة |
|---|---|
| `ANTHROPIC_API_KEY` | مفتاح Claude |
| `PEXELS_API_KEY` | مفتاح Pexels |
| `YOUTUBE_CLIENT_ID` | من الخطوة 4 |
| `YOUTUBE_CLIENT_SECRET` | من الخطوة 4 |
| `YOUTUBE_REFRESH_TOKEN` | من الخطوة 4 |

(اختياري) في تبويب **Variables**: `SHORTS_NICHE` لتغيير مجال القناة، `SHORTS_VOICE` لتغيير الصوت (مثلاً `ar-EG-ShakirNeural` مصري، `ar-SA-ZariyahNeural` نسائي).

### 6) شغّل
**Actions ← Daily Shorts ← Run workflow**. بعدها يشتغل لوحده يومياً الساعة ~5 مساءً و~9 مساءً بتوقيت الرياض.

> ملاحظة: الجدولة التلقائية في GitHub تعمل فقط من الفرع الافتراضي للمستودع (main).

## الدخل: التوقعات الواقعية 💰

- **شروط تفعيل الربح (YouTube Partner Program):** 1,000 مشترك + 10 ملايين مشاهدة شورتس خلال 90 يوماً للحصول على نصيب من الإعلانات. (هناك مستوى أقل: 500 مشترك + 3 ملايين مشاهدة شورتس يفتح ميزات دعم المعجبين فقط.)
- **عائد الشورتس منخفض:** غالباً بين 0.02 و0.10 دولار لكل 1000 مشاهدة، وأقل للجمهور العربي من الأمريكي. يعني مليون مشاهدة ≈ 20–100 دولار.
- **سياسة "المحتوى غير الأصيل":** يوتيوب يرفض تحقيق الربح للمحتوى المتكرر المنتج بالجملة. لذلك النظام يكتب كل نص جديداً، بحقائق مختلفة وصور مختلفة. لرفع فرص القبول: راجع الفيديوهات أحياناً، نوّع المجال، وفكّر لاحقاً بتسجيل صوتك بدل الصوت الآلي.
- **مصادر دخل أسرع من الإعلانات:** روابط أفلييت في الوصف (أمازون مثلاً)، توجيه المشاهدين لقناة فيديوهات طويلة (عائدها أعلى بكثير)، والرعايات بعد ما تكبر القناة.

**الخلاصة:** النظام يتكفل بالإنتاج والنشر اليومي المنتظم – وهو أصعب جزء. النجاح يحتاج 2–6 أشهر من النشر المستمر ومتابعة الإحصائيات (أي المواضيع تنجح ← زد منها عبر `SHORTS_NICHE`).

## للمطورين

```bash
pip install -r requirements.txt     # يحتاج ffmpeg مثبت
cp .env.example .env                # عبّئ المفاتيح
python -m shorts                    # يصنع فيديو في output/
python -m shorts --count 3 --upload # يصنع 3 ويرفعها
python -m shorts --offline          # بدون Claude (بنك الأفكار الجاهز)
python -m pytest -q
```

| الملف | الوظيفة |
|---|---|
| `shorts/content.py` | توليد الفكرة والنص والعنوان والوسوم |
| `shorts/voice.py` | التعليق الصوتي، مقطع لكل جملة لتزامن دقيق |
| `shorts/captions.py` | الترجمة المتحركة وشريط التقدم (ASS) |
| `shorts/background.py` | فيديوهات Pexels أو خلفية متدرجة |
| `shorts/render.py` | تركيب الفيديو النهائي 1080×1920 |
| `shorts/upload.py` | الرفع على يوتيوب |
| `data/history.json` | المواضيع المنشورة (لعدم التكرار) |

موسيقى خلفية (اختياري): ضع ملفات mp3 مرخّصة (مثل مكتبة YouTube Audio Library) في `assets/music/`.

الخط: Noto Sans Arabic (رخصة OFL – `assets/fonts/OFL.txt`).
